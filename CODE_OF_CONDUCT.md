# Código de Conducta

Este proyecto es un espacio de trabajo técnico. Se espera respeto y
profesionalidad; no se toleran el acoso, la discriminación ni los ataques
personales.

## Comportamiento esperado

- Criticar ideas y código, no personas.
- Dar contexto reproducible cuando se reporta un fallo.
- Aceptar que el mantenedor puede rechazar cambios por alcance, riesgo o falta
  de tests.
- Respetar la privacidad y no publicar datos personales, tokens ni detalles
  explotables de seguridad.

## Comportamiento inaceptable

- Insultos, amenazas, acoso o comentarios discriminatorios.
- Publicar vulnerabilidades sin coordinar o sin dar tiempo a corregirlas.
- Spam, suplantación de identidad o divulgación de información privada.
- Cualquier conducta que, en un contexto profesional, sería claramente
  inapropiada.

## Alcance

Aplica a issues, pull requests, discusiones, revisiones y cualquier espacio del
proyecto. También aplica cuando se representa al proyecto en otros espacios.

## Reporte

Si sufres o presencias una conducta inaceptable, contacta en privado con el
mantenedor ([@majhrs16-official](https://github.com/majhrs16-official)) por
GitHub. No uses un issue público para reportar incidentes con datos personales.

## Aplicación

El mantenedor puede pedir que se detenga una conducta, editar o borrar
comentarios, cerrar hilos y, si es necesario, bloquear temporal o
permanentemente a una persona. No hay un comité formal ni un proceso de
apelación; se actuará de forma razonable y proporcional.

Este texto se inspira en el [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
adaptado a un proyecto mantenido por una sola persona.
